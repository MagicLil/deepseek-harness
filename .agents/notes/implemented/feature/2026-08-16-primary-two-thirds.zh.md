# Agent Note: 左侧栏拖到窗口三分之二

Status: implemented

English | [2026-08-16-primary-two-thirds.md](2026-08-16-primary-two-thirds.md)

## 问题

只把 `WORKBENCH_MAX` 提到 800px 不够。拖左侧栏会先写下更大的偏好，随后 `computeColumns` 仍优先保住对话，再为了编辑器 400px 地板把左侧栏挤回去。对话列已经能到窗口三分之二，Git / 资源管理器列做不到。

## 决策

左侧栏上限与对话列相同：`floor(视口 * 2 / 3)`。正在拖左侧栏时（`prefer: 'primary'`）先收缩再关闭对话，必要时编辑器可以低于 400px——和拖对话到 2/3 是镜像。松手时把两列偏好一起写回，避免下一次静止重绘把侧栏弹回去。

## 考虑过的替代

**只保留 800px 上限、加大拖动手柄。** 否决：求解器仍会为对话和编辑器地板让掉左侧栏。

**拖宽时自动收起最右会话列表，好让 2/3 仍保住 400px 编辑器。** 否决：会话列不在这条分隔条上；拖对话时本来就会挤编辑器。

## 后果

把左侧栏拖很宽可能关掉对话、挤窄编辑器，和把对话拖很宽会挤掉资源管理器一样。桌面要重建 `ui-layout`（`lib/client.js`）后新上限才会画出来。
