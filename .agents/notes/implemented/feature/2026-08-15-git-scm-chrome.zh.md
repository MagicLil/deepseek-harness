# Agent Note：Cursor 式 Git SCM 外观

Status: implemented

[English](2026-08-15-git-scm-chrome.md) | 中文

## 问题

Git 页已经有 Cursor 的两栏更改和用户点击同步，但外壳仍像一张表：标题写着 `GIT`、带边框的仓库/分支下拉、很粗的「创建分支」行、带字的提交按钮，下面是 `hash + 说明` 列表。工作区干净时，整个面板看起来像日志浏览，不像源代码管理。

## 决策

**L2 对齐 Cursor 的源代码管理外观。** 活动栏标题是「源代码管理」。工具条是看起来像文字的分支选择、带 `↑` / `↓` 的同步图标，以及刷新图标。更改行是彩色文件徽标、文件名、淡目录、悬停操作，右侧是 `M` / `A` / `D`。历史是「图表」：按新到旧上色的 lane，加上提交说明。

**`host.gitLog` 带可选 `parents`（L3）。** `git log` 格式含 `%P`。没有父提交时省略该字段，旧客户端仍能读。没有 `parents` 时，画图退回单条脊柱。

**这一刀仍然不做：** Agent Review。AI 写提交说明、引用标签、从图上切提交见 [AI/图表笔记](2026-08-15-git-scm-ai-graph.md)。

## 考虑过的替代

**只给旧表单换 CSS。** 否决：带边框的下拉和 hash 列表看起来仍是仪表盘，截图里的差距就是这个。

**搬一个 Git Graph webview。** 否决：桌面端没有页面 WebSocket，第三方面板也走不了 `host.git*` IPC。

## 后果

工作区干净时仍显示图表，面板不会收成空壳。主机返回 `parents` 时，合并提交会打开第二条 lane。创建分支输入仍留在面板上，做成细行，因为日常 Git 还要用；没有收进溢出菜单。
