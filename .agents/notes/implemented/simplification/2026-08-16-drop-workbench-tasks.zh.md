# Agent Note：去掉工作台「任务」活动项

Status: implemented

[English](2026-08-16-drop-workbench-tasks.md) | 中文

## 问题

活动栏「任务」图标打开的左侧面板几乎总是写着「没有正在执行的任务 / 没有子代理」。当前回合、后台作业和子代理本来就在对话列里。空面板占着资源管理器和 Git 旁边的一个槽位。

## 决定

删掉内置 `tasks` 活动项和它的隐藏 tab。活动栏和「视图」菜单只留资源管理器与 Git。桌面原生菜单和 IPC 命令字去掉 `activity-tasks`。持久化里的 `activity: "tasks"` 会落到资源管理器。`SHELL_TAB_TYPES` 仍保留 `tasks`，避免旧持久化标签跑到中间编辑器条上。

## 考虑过的方案

**只藏图标、保留 tab 类型。** 否决：没有入口的注册体是死代码，apply 里作业/子代理接线也只为这块面板服务。

**桌面菜单仍留「视图 → 任务」。** 否决：点开什么都没有，和鸡肋图标是同一件事。

## 后果

左侧轨道只剩资源管理器和 Git。插件仍可 `registerActivity`。作业终止/输出和以后的任务页，除非产品再要，否则不做。
