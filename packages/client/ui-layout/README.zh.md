# @deepseek-ai/dsh-client-ui-layout

[English](README.md) | 中文

外壳插件：Cursor 式 AppFrame（拖动手柄与让步链）加 `ctx.layout` 面板几何服务；它注册到运行时拥有的 `root` slot，并声明 `menuBar`、`activityBar`、`primarySidebar`、`workbench`、`bottomPanel`、`conversation`、`details`、`sidebar` 和 `shell.overlay`。顶部 28px 的 `menuBar` 在 web 上横贯整窗，不可拖、不让步。桌面 `dsh:` 渲染进程会藏掉这一独立行，把同一套 HTML 应用菜单（文件 / 编辑 / 视图 / 终端 / 帮助）画进 32px 标题轨道，下拉菜单走 portal，避免被 32px 裁掉。桌面用隐藏标题栏加系统最小化/最大化/关闭叠加；轨道是 flex 行（品牌、菜单、拖拽空白、对话开关），宽度落在 `titlebar-area-width` 内，且不超过窗口减去 Windows 标题按钮的宽度，开关不会藏到最小化下面。顶栏用侧栏同款底色加底边，和下面各栏读成同一套窗口铬。下面各栏从下一行开始，顶栏不会盖住内容。`openConversation` / `closeConversation` / `toggleConversation` 把对话列收到零宽（再打开恢复 380px 默认）。水平轨道为活动栏（48px，不可拖）| 左侧边栏 | 编辑器（`minmax(0, 1fr)`）| 对话 | 详情 | 会话列表。底栏只占编辑器那一列。左侧边栏、对话、详情和会话列的缩放边界是 Cursor 式分隔条（每条边悬停出通高高亮线，没有浮动胶囊；左侧栏和对话列都能拖到窗口三分之二）；拖拽过程只在 DOM 上画网格轨道，松手才把宽度写回 store，避免编辑器/对话整树按指针节拍重绘。指针按下会在第一次写宽之前给框架打上 `data-dragging`，避免网格缓动把编辑器轨道闪一下，编辑器列本身保持不透明隔离层。让步时先关详情，再让正在拖的那一列赢：拖对话就收缩/关闭左侧栏，拖左侧栏就收缩/关闭对话，两边都能到窗口三分之二。静止重绘仍优先保住对话。点击活动栏图标（资源管理器 / Git）会走 `openWorkbench`：若对话列已把左侧栏让到零宽，就收一点对话，让资源管理器与编辑器对分剩余空间（优先 400/400）。活动栏永不让步。对话列和左侧栏的拖拽上限都是 `floor(视口 * 2 / 3)`，不再写死像素上限。底栏 store 上限按 4K 高窗口留出 160px 编辑器地板；实际绘制仍缩到 frameHeight - 160，编辑器不会被吃光。关闭的会话列仍保留 56px 控制栏；关闭的详情 / 对话 / 左侧边栏为零宽度。编辑器地板为 400px。该包还提供主题呈现器：它消费解析后的 `ctx.theme` 快照，并将其投影到 document（用 `html { color-scheme }` 驱动原生 UA 控件，依据当前配色方案设置 `body[data-ds-dark-theme]`，并将主题的别名 token 设为 body 上的内联变量，同时拥有一个 `<meta name="theme-color">`，其内容随计算后的 body 背景色更新）。在应用调色板和 token 后进行测量，可确保渲染后的背景成为唯一的颜色依据；呈现器在 dispose（资源释放）时会移除其自有的元数据节点，并一并清除其写入的其他全局状态。

AppFrame 始终挂载会话栏、详情栏、编辑器栏和会话列表；已连接 Session 通过 `SessionProvider` 渲染。布局 store 是瞬时状态，会话列、对话列和左侧边栏以默认宽度启动，详情栏与底栏保持关闭，且该 store 从不读写 `localStorage`。hero 和其他未选中状态会将详情栏与左侧边栏的渲染宽度派生为零，但不会改变存储的宽度偏好。空白「新会话」仍打开左侧边栏，让资源管理器能显示该项目目录；详情栏保持关闭，直到会话有内容。AppFrame 会跨越这些状态保留最后一个非 blank 会话 id：首个会话保持详情关闭；显式打开详情栏的操作会使用约定默认宽度；返回同一会话时恢复其未改变的宽度；选择不同会话时，详情栏会在绘制前关闭，若对话列已收起则会重新展开。`openWorkbench` / `closeWorkbench` / `toggleWorkbench` / `setWorkbench` 驱动左侧边栏（编辑器轨道始终可见）。`openWorkbench` 仅在左侧栏已经画出非零宽度时才是空操作；对话列拖到 2/3 把左侧栏让到零宽时，会收缩对话列，好让点击能打开资源管理器 / Git。`toggleSidebar` 仍驱动最右会话列。`toggleConversation` 驱动对话列。会话与详情栏 owner share 为空，侧边栏 owner share 只包含 `collapsed` 和 `width`，工作台 owner share 是求解后的编辑器宽度；活动栏 / 左侧边栏 / 底栏 owner share 携带实时开关标志和轨道尺寸。注册方通过标准钩子获取业务数据，并从各自的 inject 接口获取操作。

`/client` 导出表层包含插件主体（`apply`／`inject`）、`LayoutController` 和各 owner-share 接口。AppFrame、面板 store 与让步求解器仍属于包内部。

## 模型体验

无。布局外壳管理浏览器查看状态；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **面板几何信息是瞬时状态**：重新加载会恢复会话列、对话列和左侧边栏的默认值，并使详情栏与底栏保持关闭；在不同会话 id 之间切换同样会关闭详情栏并忘记其拖动宽度，但左侧边栏偏好会保留，以便占用方按会话重新应用记忆；未选中表面会以零宽度渲染详情栏与左侧边栏，但不会修改几何信息。
- **让步链自动关闭通过推导零宽度实现，不会改动宽度偏好**：窗口变宽时面板会自行恢复；消费方禁止把 store 中的详情栏或左侧边栏宽度当作实际渲染状态。例外是用户显式 `openWorkbench` / 打开方向的 `toggleWorkbench`：这时可以改写对话列偏好，好让左侧栏画得出来。
- **挤压重排期间不提供滚动锚定**：布局变化可能移动读者的 viewport。
