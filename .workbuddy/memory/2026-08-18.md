# 2026-08-18

## 调试：`pnpm dsh desktop` 启动失败

**现象**：`apps/desktop/src/relaunch.ts:59` 抛 "the electron package is not installed"。
**真因**：`require('electron')` 加载 `electron/index.js:21` 时，
`getElectronPath()` 读不到 `path.txt` 且 `dist/` 缺失 → 抛
"Electron failed to install correctly"。被 relaunch.ts 的 catch 包装成了"没装 electron"。

**排查要点**：
- electron 包在 `.pnpm/electron@37.2.0_supports-color@9.4.0/node_modules/electron`
- 二进制 zip 其实已下载到缓存 `$LOCALAPPDATA/electron/Cache/.../electron-v37.2.0-win32-x64.zip`
- 只是 `dist/` 与 `path.txt` 没被解压出来（install 脚本没跑到最后）

**修复**：在该 electron 目录下执行
`ELECTRON_MIRROR="https://registry.npmmirror.com/-/binary/electron/" node install.js`
复用缓存秒级解压，生成 `dist/electron.exe` 与 `path.txt`。

**经验**：本机 npm 用 npmmirror 镜像但未设 `ELECTRON_MIRROR`，
electron 二进制默认走 GitHub 下载易失败。后续若再遇 electron 二进制缺失，
直接跑 install.js + 设 `ELECTRON_MIRROR` 即可，不用重装整个 node_modules。
`apps/desktop/lib/electron-main.js` 已构建（17:42），第二道关卡已满足。
